## Application-data migration

The current application-data root is `%AppData%\KARZOUN ERP` and the current
database is `karzoun_erp.db`.

At startup, `AppDataMigration` checks the legacy `%AppData%\FornixxCRM` location.
If the current database does not exist and the legacy database does, it uses the
SQLite backup API to create a consistent temporary copy, rebuilds indexes only in
that copy, verifies full SQLite integrity, and atomically moves the verified copy
to the current database name. Other legacy settings, logs, recovery backups, and
product images are copied only when the corresponding destination file does not
already exist.

If legacy localized-company settings contain duplicate `(CompanyId, LanguageCode)`
rows that prevent rebuilding the required unique index, the oldest row remains
active and every additional row is preserved in full in
`DataMigrationArchive_CompanyLocalizedSettings` inside the new database. The
legacy database remains unchanged.

The migration never deletes or writes to the legacy directory, never overwrites an
existing KARZOUN ERP database or file, and is safe to run repeatedly. A failed
database copy stops startup instead of allowing creation of an empty replacement.
Legacy backup files remain valid inputs to the existing restore flow.

## Installer preparation

`installer/KarzounERP.iss` is prepared for a future Inno Setup build named
`KARZOUN_ERP_Setup_1.1.0.exe`. No installer is generated by the rebrand work.
Because the previous installer definition/AppId is not present in this source,
Windows installer in-place upgrade continuity with an older installer cannot be
verified yet. The new installer uses a stable AppId for future upgrades and does
not remove application data during uninstall or upgrade.

## Approved visual identity

The approved production assets are stored under `Resources/Brand`: the application
and executable use `AppIcon.ico`, the future setup uses `InstallerIcon.ico`, and the
sidebar uses the non-mirrored transparent `Karzoun_Mark.png`. The former letter-A
icon has been removed after verifying the icon embedded in `KARZOUN_ERP.exe`.

`KarzounBrand.xaml` is the central palette/semantic-resource dictionary. Appearance
settings continue to override the application brushes, and enabled company themes
continue to override the intended primary, secondary, and accent brushes. Surface
luminance selects the matching Material Design light/dark base automatically;
Karzoun Light and Karzoun Dark presets are available without changing PDF/company
document settings.

The approved Sora, Inter, IBM Plex Sans Arabic, and Tajawal font files are not
bundled because they were not present in the source and no redistribution license
was supplied. WPF uses named fallbacks to Segoe UI/Tahoma/Arial. To ship the exact
typography later, obtain redistributable font files and licenses, add them as WPF
resources, and replace the fallback family resources in `KarzounBrand.xaml`.
